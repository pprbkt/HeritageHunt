# Heritage Hunt Mysuru — Local Media Assets

Place your high-resolution video, audio, and image files in the subdirectories below:

- `public/assets/videos/`
- `public/assets/images/hero/`
- `public/assets/images/landmarks/`
- `public/assets/images/programs/`
- `public/assets/images/archives/`
- `public/assets/audio/`

See `media_asset_inventory.md` for the exact file naming conventions and recommended resolutions.
